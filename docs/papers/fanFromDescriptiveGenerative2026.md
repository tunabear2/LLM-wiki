# From descriptive to generative: foundation-model approaches for spatial transcriptomics

## 1. 한 줄 요약

"Cells as words, tissues as sentences" 관점에서 Transformer, state-space, diffusion 기반 spatial transcriptomics FM을 domain identification, interaction inference, cross-modal alignment과 generation task로 정리한다.

## 2. 왜 중요한가

Spatial FM의 기술 계열과 응용을 하나의 conceptual framework로 묶으면서 perturbational·spatiotemporal inference에는 더 엄격한 검증이 필요하다고 강조한다. 새 모델의 비교 기준과 claim 수준을 정리하는 데 유용한 review다.

## 3. 내 연구에 연결할 점

Kidney transplant spatial analysis에서 descriptive annotation, cross-modal reconstruction, perturbation prediction을 구분하고, 각 단계마다 donor·section holdout과 Banff lesion·graft function 같은 독립 endpoint를 연결하는 설계 참고가 된다.
