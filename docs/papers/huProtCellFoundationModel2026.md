# ProtCell: A Foundation Model for Single-Cell Proteomics

## 기본 정보

- Citation key: `huProtCellFoundationModel2026`
- Item type: preprint
- Authors: B. Hu; Z. Li; Q. Jiang; Q. Yin; Z. Liu; R. Jiang
- DOI: 10.64898/2026.10.22.760932
- URL: [Link](https://doi.org/10.64898/2026.10.22.760932)
- Source/date: bioRxiv v1, posted 2026-10-27

## 1. 한 줄 요약

ProtCell은 98개 dataset의 약 3억 8,000만 cell에서 protein identity와 continuous abundance를 masked modeling해 서로 다른 targeted panel을 잇는 single-cell proteomics foundation model이다.

## 2. 왜 중요한가

Fragmented protein panel 사이의 annotation과 batch correction, 미측정 abundance 및 cytotoxic program 복원, compact panel 선택을 하나의 pretrained representation으로 다룬다. Transcriptome 중심 scFM을 직접적인 functional readout인 protein 공간으로 확장한다.

## 3. 내 연구에 연결할 점

Rejection biopsy의 CITE-seq, imaging proteomics 또는 flow panel에서 NK·memory CD8 cytotoxic program과 제한된 marker panel을 연결할 후보지만, kidney tissue coverage와 panel-missingness OOD를 별도로 검증해야 한다.
