# AI Scientists for Building Virtual-Cell Models

## 1. 한 줄 요약

CellForge는 문헌 조사부터 model hypothesis, code, training과 validation까지 수행해 single-cell perturbation predictor를 만드는 autonomous multi-agent workflow다.

## 2. 왜 중요한가

Transcriptomic, epigenomic, proteomic perturbation dataset 여섯 개에서 human-specified architecture 없이 모델을 만들고 handcrafted baseline과 경쟁한다. Agent가 제안한 architecture 자체를 검증 가능한 과학 가설로 다루며 paired multi-omics까지 확장한다.

## 3. 내 연구에 연결할 점

Kidney rejection perturbation model 설계 자동화에 참고할 수 있지만 agent plan의 설득력과 biological validity는 분리해야 한다. Data leakage, baseline 선택, donor/cell-type holdout, code 재현성과 renal perturbation validation을 사람이 사전 고정해야 한다.
