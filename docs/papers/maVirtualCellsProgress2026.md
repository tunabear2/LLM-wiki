## 1. 한 줄 요약

Virtual cell을 state encoding, transition과 observation decoding으로 나눠 mechanistic, foundation, perturbation, multimodal 및 spatial model의 근거와 한계를 비교한 review다.

## 2. 왜 중요한가

Parameter 수와 training scale이 OOD generalization을 자동 보장하지 않으며 transcriptomic representation만으로 cell function 전체를 설명할 수 없다고 정리한다. Perturbation-responsive transition, cross-modal alignment, uncertainty와 독립 실험 검증을 핵심 요건으로 제안한다.

## 3. 내 연구에 연결할 점

Kidney rejection virtual cell을 static embedding과 intervention model로 분리하고 donor·time·drug·cell-state OOD를 명시하는 설계 틀이다. Spatial pathology, graft function과 organoid/perturbation validation을 observation layer로 연결해야 한다.
