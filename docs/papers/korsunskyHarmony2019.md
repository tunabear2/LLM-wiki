## 1. 한 줄 요약

Harmony는 batch/dataset-specific effect를 줄이면서 cell type structure를 보존하도록 shared embedding을 학습하는 single-cell integration algorithm이다.

## 2. 왜 중요한가

여러 donor, tissue, technology를 합치는 atlas-scale single-cell analysis에서 빠르고 실용적인 batch correction baseline이 되었다.

## 3. 내 연구에 연결할 점

Kidney transplant biopsy는 center, protocol, patient condition 차이가 크므로, foundation model embedding을 쓰더라도 Harmony 같은 classical integration baseline과 비교해야 한다.
