# Learning Interpretable Tumor Microenvironment Representations by Fitting Pan-Cancer Cell State-Niche Correlation

## 기본 정보

- Citation key: `xiaoLearningInterpretableTumor2026`
- Item type: preprint
- Authors: Xiao Xiao; Jiashu He; Shiyang Zhang; Meiyi Mao
- DOI: 10.48550/arXiv.2608.26208
- URL: [Link](https://arxiv.org/abs/2608.26208)
- Source/date: arXiv v1, 2026-08-26

## 1. 한 줄 요약

GITIII-scale은 paired scRNA-seq와 imaging spatial transcriptomics로 cell state–niche correlation과 ligand–receptor mechanism을 학습하는 pan-cancer spatial foundation model이다.

## 2. 왜 중요한가

Cell pair transformer, 해석 가능한 단일-layer graph transformer, neighborhood encoder를 계층적으로 사용해 unseen cancer의 niche-associated state change와 candidate ligand–receptor pathway를 복원한다.

## 3. 내 연구에 연결할 점

Rejection biopsy에서 immune–endothelial–tubular cell interaction과 Banff lesion을 연결하는 architecture 참고가 된다. Cancer-trained representation의 직접 전이보다 transplant paired scRNA/spatial data에서 재학습하고 ligand–receptor 결과를 orthogonal assay로 검증해야 한다.
