## 1. 한 줄 요약

scVI는 single-cell count data의 noise와 uncertainty를 확률적 generative model로 다루는 variational inference framework다.

## 2. 왜 중요한가

Single-cell embedding, batch correction, imputation, differential expression에서 deep generative modeling을 표준 도구로 끌어올렸다. 이후 scArches, totalVI, multiVI 같은 scverse model의 기반이 된다.

## 3. 내 연구에 연결할 점

Transplant biopsy cohort 간 batch, donor, protocol 차이를 모델링할 때 scVI embedding을 scGPT/scFoundation embedding의 강력한 non-foundation baseline으로 둬야 한다.
