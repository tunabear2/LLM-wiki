# BioMeme: biological response memory for virtual cells

## 1. 한 줄 요약

BioMeme는 virtual-cell response layer를 이름이 붙은 실험 측정치의 memory와 가중합으로 바꿔, 예측 근거를 추적하고 새 실험을 빠르게 반영한다.

## 2. 왜 중요한가

새 cell type의 저용량 상태와 reference cell의 같은 compound response를 함께 검색한다. 세 screen의 아홉 preregistered comparison에서 response direction을 neural learner보다 잘 맞췄고, 작은 reference set은 CPU에서 수초 내 갱신되어 재학습 비용과 black-box 근거 문제를 동시에 줄인다.

## 3. 내 연구에 연결할 점

Kidney-transplant cytokine·immunosuppressant dose response를 실제 donor experiment와 연결하는 auditable baseline이 될 수 있다. 다만 결과가 U2OS·MCF7 중심이므로 renal immune·endothelial·tubular state, donor와 time-course holdout에서 먼저 검증해야 한다.
