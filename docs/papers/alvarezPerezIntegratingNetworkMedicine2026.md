# Integrating network medicine and foundation models reveals cell-type-specific regulatory alterations in Alzheimer's disease

## 1. 한 줄 요약

130만 개 이상의 cell과 18개 cell type에서 SCANet의 co-expression·GRN module과 scGPT gene prioritization을 결합해 Alzheimer disease의 cell-type-specific regulatory alteration을 분석한다.

## 2. 왜 중요한가

scGPT와 network method는 gene 수준에서는 대체로 수렴하지만 higher-order architecture 일치는 제한적이고 cell type에 따라 달랐다. Foundation-model attribution과 interpretable network가 서로 대체재라기보다 상보적이라는 사례다.

## 3. 내 연구에 연결할 점

Rejection-associated immune·endothelial·tubular cell에서 scGPT 우선순위 gene이 renal GRN module 안에 모이는지 확인하고, network rewiring과 perturbation evidence로 후보를 교차 검증할 수 있다.
