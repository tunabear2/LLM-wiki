# scMaize: A Single-Cell Foundation Model and Integrated Atlas for Maize

## 기본 정보

- Citation key: `chengScMaizeSingleCell2026`
- Item type: preprint
- Authors: Qian Cheng; Ying Zhang; Tianhao Wu; Anwen Zhao; Meiqi Shang; Xiangfeng Wang; Jun Yan
- DOI: 10.64898/2026.08.01.742180
- URL: [Link](https://www.biorxiv.org/content/10.64898/2026.08.01.742180v1)
- Source/date: bioRxiv v1, posted 2026-08-05

## 1. 한 줄 요약

385,675개 maize cell atlas와 GO functional embedding을 결합한 species-specific single-cell foundation model scMaize를 제안한다.

## 2. 왜 중요한가

Expression-only model과 GO-prior model을 비교해 biological prior가 rank prediction, attention coherence, embedding과 few-shot cross-species classification에 주는 영향을 평가한다. Domain-specific corpus와 structured prior를 함께 설계하는 사례다.

## 3. 내 연구에 연결할 점

식물 모델이라 kidney transplant에 직접 전이할 수는 없지만, kidney/immune-specific ontology나 GRN prior를 넣은 scFM을 expression-only model과 비교할 때 leakage와 prior 의존성을 점검하는 설계 참고가 된다.
