# Autonomous generalizability auditing of scientific foundation models

## 기본 정보

## 1. 한 줄 요약

AutoSPECTRA는 coding agent가 prespecified generalization axis와 controlled comparison을 따라 STATE 등 scientific FM의 실패 경계를 자동 감사하도록 구조화한다.

## 2. 왜 중요한가

자유로운 agent 분석은 evidence 판단 기준이 불일치했지만, 측정 가능한 axis와 대안 설명 검정을 강제하자 STATE에서는 training에 포함된 perturbation 표현이 generalization과 연결됐다. 자동 분석 자체보다 audit protocol의 통제가 핵심임을 보여준다.

## 3. 내 연구에 연결할 점

Kidney rejection virtual-cell model의 donor·cell type·drug·center shift를 agent로 탐색할 수 있지만, split·metric·negative control과 독립 확인을 사람이 먼저 고정해야 한다.
