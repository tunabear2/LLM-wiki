# SCANPY: large-scale single-cell gene expression data analysis

## 기본 정보

- Citation key: `wolfSCANPY2018`
- Item type: journalArticle
- Authors: F. Alexander Wolf; Philipp Angerer; Fabian J. Theis
- DOI: 10.1186/s13059-017-1382-0
- PMID: 29409532
- URL: [Link](https://pubmed.ncbi.nlm.nih.gov/29409532/)
- Source/date: Genome Biology, 2018

## 1. 한 줄 요약

Scanpy는 Python 기반 single-cell analysis toolkit으로 preprocessing, visualization, clustering, trajectory inference, differential expression을 scalable하게 제공한다.

## 2. 왜 중요한가

AnnData 생태계와 함께 Python single-cell workflow의 표준 축이 되었다. 대규모 cell atlas와 machine learning pipeline을 연결하기 좋다.

## 3. 내 연구에 연결할 점

Kidney biopsy scRNA-seq 분석에서 QC, normalization, clustering, marker detection, scVI/scGPT embedding 연동을 Python stack으로 구성할 때 기본 도구다.
