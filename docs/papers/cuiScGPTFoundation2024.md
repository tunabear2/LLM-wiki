# scGPT: toward building a foundation model for single-cell multi-omics using generative AI

## 기본 정보

- Citation key: `cuiScGPTFoundation2024`
- Item type: journalArticle
- Authors: Haotian Cui; Chloe Wang; Hassaan Maan; Kuan Pang; Fengling Luo; Nan Duan; Bo Wang
- DOI: 10.1038/s41592-024-02201-0
- PMID: 38409223
- URL: [Link](https://pubmed.ncbi.nlm.nih.gov/38409223/)
- Source/date: Nature Methods, 2024

## 1. 한 줄 요약

scGPT는 generative pretrained transformer를 single-cell multi-omics에 적용해 annotation, batch correction, perturbation prediction, multi-omics integration을 다루는 대표 모델이다.

## 2. 왜 중요한가

Single-cell expression profile을 gene token sequence처럼 다루고, large atlas pretraining 이후 여러 downstream task에 transfer하는 scFM workflow를 널리 알렸다.

## 3. 내 연구에 연결할 점

Kidney transplant rejection에서는 biopsy scRNA-seq annotation, cross-cohort integration, rejection/non-rejection embedding 비교, perturbation 후보 생성의 baseline으로 둘 수 있다.
