## 1. 한 줄 요약

T5는 모든 NLP task를 text-to-text 형식으로 통일하고, pretraining objective와 dataset curation이 transfer 성능에 미치는 영향을 체계적으로 비교했다.

## 2. 왜 중요한가

분류, 번역, 요약, QA를 모두 "입력 text -> 출력 text"로 다루는 interface를 정착시켰다. 모델 구조보다 task formulation과 pretraining recipe가 실제 성능에 큰 영향을 준다는 점도 보여준다.

## 3. 내 연구에 연결할 점

논문 요약, entity extraction, cohort inclusion criteria 추출처럼 출력 형식이 다양한 biomedical NLP task를 하나의 generation interface로 묶을 때 참고할 만하다.
