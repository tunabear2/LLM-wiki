## 1. 한 줄 요약

Chinchilla 논문은 같은 compute budget에서는 parameter 수만 키우기보다 training token 수도 함께 키워야 compute-optimal하다는 scaling rule을 제시했다.

## 2. 왜 중요한가

LLM scaling 논의를 "모델 크기 경쟁"에서 "model size와 data tokens의 균형"으로 옮겼다. 이후 작은 모델을 더 많은 고품질 token으로 학습하는 전략의 근거가 되었다.

## 3. 내 연구에 연결할 점

Bio foundation model에서도 "cell 수를 얼마나 늘릴지", "gene/token vocabulary와 model size를 어떻게 맞출지"를 생각할 때 Chinchilla식 compute/data balance 관점이 유용하다.
