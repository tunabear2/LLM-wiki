# Deciphering state bridges via a single-cell large language model

## 기본 정보

- Citation key: `feiDecipheringStateBridges2026`
- Item type: preprint
- Authors: Q. Fei; M. Liang; C. Cui; B. Kang; Q. Cui
- DOI: 10.64898/2026.11.21.768275
- URL: [Link](https://doi.org/10.64898/2026.11.21.768275)
- Source/date: bioRxiv v1, posted 2026-11-23

## 1. 한 줄 요약

UCE로 5,900만 cell·nucleus의 36개 cell type annotation을 통일하고 614 biological state 사이의 cell-composition bridge를 비교한다.

## 2. 왜 중요한가

8,789 human sample을 state별 36차원 composition-change vector로 요약해 22,161개 유의 bridge를 제안한다. Atlas-scale harmonization 사례지만 bridge는 주로 composition association이며 질환 간 기전적·인과적 연결을 직접 증명하지 않는다.

## 3. 내 연구에 연결할 점

Rejection, infection, ischemia-reperfusion과 CKD state 사이의 composition similarity를 탐색할 수 있다. Tissue·study confounding과 annotation transfer error를 통제하고 같은 cell type 내부 expression state 분석을 별도로 유지해야 한다.
