# A single-cell multimodal foundation model enables cross modality analysis between transcriptome and chromatin

## 1. 한 줄 요약

MUTUAL은 frozen scFoundation과 EpiAgent embedding을 300만 paired cell에서 정렬해 RNA와 ATAC 사이의 zero-shot cross-modality 분석 공간을 만든다.

## 2. 왜 중요한가

400개 public multiome dataset으로 shared space를 학습한 뒤 미사용 dataset 열 개에 refitting 없이 적용했다. RNA–ATAC matching, ATAC-only annotation과 RNA-only cell의 transcription-factor motif activity transfer를 평가한다.

## 3. 내 연구에 연결할 점

Kidney allograft에서 RNA-only biopsy에 rejection-associated regulatory activity를 옮길 후보지만, donor·disease·platform holdout과 실제 paired multiome에서 HLA·IFN motif fidelity를 확인해야 한다.
