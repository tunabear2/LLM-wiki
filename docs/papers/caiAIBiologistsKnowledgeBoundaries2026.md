# AI for Biologists: The Knowledge Boundaries of Foundation Models in the Age of Agentic Systems

## 1. 한 줄 요약

Biological foundation model의 신뢰 가능 범위를 data, architecture, training, evaluation과 post-analysis가 정하는 knowledge boundary로 체계화한 review다.

## 2. 왜 중요한가

Nucleotide, protein과 single-cell FM을 agent가 도구로 호출하는 환경에서 성능 숫자만으로는 입력·task·condition별 실패 경계를 알 수 없다고 지적한다. 모델의 적용 범위와 한계를 표준화해 기록하는 방법을 제안한다.

## 3. 내 연구에 연결할 점

Rejection pipeline에서 model card를 donor, organ, assay, cell state, perturbation과 clinical endpoint별로 나누고 boundary 밖 결과는 abstention 또는 전문가 검토로 보내는 운영 기준이 된다.
