# Pre-Registered External Evaluation Yields a Consistent Partial-Replication Category across Three Transcriptomic Foundation Models

## 1. 한 줄 요약

Pre-registered external Perturb-seq 평가에서 Geneformer·scGPT·UCE embedding은 trivial control보다 정보가 있지만 강한 expression baseline을 안정적으로 넘지 못했다.

## 2. 왜 중요한가

Outcome rule, seed와 target-gene-grouped split을 test 공개 전에 고정하고 expression, matched-capacity Gaussian, row-shuffle control을 함께 둔다. RPE1·K562 모두에서 세 모델이 partial-replication category에 머물러 cross-architecture transfer claim에 엄격한 기준을 제시한다.

## 3. 내 연구에 연결할 점

Rejection perturbation 또는 drug-response 예측에서 patient·target 분리, final-test-once, expression baseline과 shuffle control을 사전 등록하고, scFM embedding의 작은 증가분을 모델 용량 효과와 분리해야 한다.
