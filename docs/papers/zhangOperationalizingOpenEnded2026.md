# Operationalizing open-ended biological discovery across single-cell representations

## 기본 정보

- Citation key: `zhangOperationalizingOpenEnded2026`
- Item type: preprint
- Authors: Ningxuan Zhang; Ziwei Wang; Ning Xie; Na Liu
- DOI: 10.48550/arXiv.2609.00681
- URL: [Link](https://arxiv.org/abs/2609.00681)
- Source/date: arXiv v1, 2026-09-01

## 1. 한 줄 요약

PROSPECTor는 conventional expression과 여러 foundation-model embedding에서 재현 가능한 single-cell structure를 탐색하고 외부 cohort 투영으로 검증 가능한 가설을 선별한다.

## 2. 왜 중요한가

정해진 phenotype을 맞히는 closed task 대신 representation space에서 먼저 신호를 찾고, 독립 single-cell·bulk·spatial cohort에서 generalizability와 phenotype association을 확인하는 auditable open-ended discovery workflow를 제시한다.

## 3. 내 연구에 연결할 점

Rejection label에만 맞춘 분석을 넘어 면역·내피·섬유화 program을 여러 embedding에서 탐색한 뒤 독립 이식 cohort와 spatial lesion에서 재현되는 후보만 후속 실험으로 보내는 데 직접 적용할 수 있다.
