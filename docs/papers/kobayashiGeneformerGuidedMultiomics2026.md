# Geneformer-guided multiomics integration identifies Pbx1 as a network hub of hematopoietic stem cell aging

## 기본 정보

- Citation key: `kobayashiGeneformerGuidedMultiomics2026`
- Item type: journal article

- DOI: 10.1126/sciadv.aeb1346
- PMID: 42627902
- URL: [Link](https://pubmed.ncbi.nlm.nih.gov/42627902/)

## 1. 한 줄 요약

Fine-tuned Geneformer와 transcriptomic·epigenetic profiling, transcription-factor screen을 결합해 aged hematopoietic stem cell의 Pbx1 regulatory hub를 찾고 실험적으로 검증한다.

## 2. 왜 중요한가

Foundation model의 embedding과 in silico perturbation을 단독 결론으로 쓰지 않고 ATAC/RNA profiling과 functional screen으로 좁혀 biological mechanism을 검증한 application 사례다.

## 3. 내 연구에 연결할 점

Rejection-associated TF나 marker를 Geneformer로 우선순위화한 뒤 chromatin accessibility, independent cohort, perturbation 또는 pathology evidence를 결합하는 multi-evidence validation 설계에 참고할 수 있다.
