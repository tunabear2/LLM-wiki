# ISP Platform powered by Geneformer: Framework for Cross-Species, Sequential, and Multi-Gene In Silico Perturbation Screens with Application to iPS Cell State Transitions

## 기본 정보

- Citation key: `sanakiISPPlatformPowered2026`
- Item type: preprint
- Authors: Yuya Sanaki; Shuji Shigenobu; Ryusuke Niwa
- DOI: 10.64898/2026.09.17.752497
- URL: [Link](https://doi.org/10.64898/2026.09.17.752497)
- Source/date: bioRxiv v1, posted 2026-09-24

## 1. 한 줄 요약

ISP Platform은 Geneformer 기반 cross-species, sequential, multi-gene in silico perturbation을 코드 없이 실행하며 iPSC reprogramming factor 순서와 조합을 탐색한다.

## 2. 왜 중요한가

Human·mouse model과 input species를 독립적으로 선택하고, 앞선 perturbation의 예측 state를 다음 단계 입력으로 연결해 순차·조합 screen을 자동화한다. Human model을 mouse cell에 적용한 결과와 그 반대가 비대칭이었던 점은 foundation-model perturbation이 species 방향과 model corpus에 민감함을 보여준다.

## 3. 내 연구에 연결할 점

Rejection에서 cytokine, immunosuppressant와 candidate regulator의 순차·조합 효과를 탐색하는 인터페이스로 참고할 수 있다. 예측 state를 반복 입력하면 오차가 누적될 수 있으므로 renal cell type, donor, treatment 순서를 분리하고 실제 combination perturbation으로 검증해야 한다.
