## 1. 한 줄 요약

Virtual knockout 방법을 GRN, latent·compositional, graph·optimal-transport·dynamical model과 foundation-model representation으로 나누고 intervention과 representation ablation을 구분한 review다.

## 2. 왜 중요한가

Held-out gene, cell type, context, combination, chemical structure와 dose를 서로 다른 generalization regime으로 정리한다. 공간·cross-modal 제약, calibrated uncertainty와 prospective validation을 갖춘 holographic virtual cell은 미래 기준이지 현재 달성된 임상 역량이 아니라고 명시한다.

## 3. 내 연구에 연결할 점

Rejection target prioritization에서 embedding token 삭제를 실제 gene knockout 효과로 해석하지 않도록 하는 기준이다. Cell-type·donor·drug OOD, dose와 spatial niche를 분리한 benchmark와 wet-lab validation이 필요하다.
