# VINTER: a generative vision-language model for annotating and interrogating spatial tissues

## 기본 정보

- Citation key: `wuVINTERGenerativeVisionLanguage2026`
- Item type: preprint
- Authors: J. Wu; W. Xu; Y. Zhuang; Y. Zhang; M. d. J. Loza Lopez; Y. Yang; K. Nakai
- DOI: 10.64898/2026.10.01.752251
- URL: [Link](https://doi.org/10.64898/2026.10.01.752251)
- Source/date: bioRxiv v1, posted 2026-10-08

## 1. 한 줄 요약

VINTER는 145만 histology-caption pair로 정렬한 generative vision-language model에 image, measured gene expression, spatial neighborhood를 한 sequence로 입력해 tissue annotation과 editable molecular evidence를 제공한다.

## 2. 왜 중요한가

형태·유전자·이웃 정보를 함께 읽고 target label 없이 cohort와 Visium HD·single-cell Xenium으로 전이한다. Gene text를 바꿔 image를 고정한 채 evidence를 질의할 수 있지만, 이 편집이 causal intervention이 아니라 model sensitivity라는 점은 구분해야 한다.

## 3. 내 연구에 연결할 점

Kidney rejection의 tertiary lymphoid structure, immune–tubular interface와 Banff lesion을 multimodal하게 읽는 후보이며, 환자·slide 외부 검증과 gene-edit counterfactual의 biological validation이 필요하다.
