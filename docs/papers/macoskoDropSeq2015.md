# Highly Parallel Genome-wide Expression Profiling of Individual Cells Using Nanoliter Droplets

## 기본 정보

- Citation key: `macoskoDropSeq2015`
- Item type: journalArticle

- DOI: 10.1016/j.cell.2015.05.002
- PMID: 26000488
- URL: [Link](https://pubmed.ncbi.nlm.nih.gov/26000488/)
- Source/date: Cell, 2015

## 1. 한 줄 요약

Drop-seq는 droplet과 barcoded bead를 사용해 수천 개 single cell의 gene expression을 병렬로 측정하는 고처리량 scRNA-seq 방법이다.

## 2. 왜 중요한가

Single-cell genomics를 소규모 plate experiment에서 atlas-scale profiling으로 확장한 platform 전환점이다. 10x Genomics류 droplet scRNA-seq를 이해하는 기본 배경이 된다.

## 3. 내 연구에 연결할 점

Transplant biopsy atlas는 droplet scRNA-seq 기반인 경우가 많아, dropout, UMI count, cell capture bias, doublet 문제를 항상 QC에 포함해야 한다.
