# Learning gene co-regulation across cells with Multicellular Transformer

## 1. 한 줄 요약

Multicellular Transformer는 한 cell이 아니라 같은 sample의 cell set을 입력으로 받아 tissue context에 따른 cross-cell gene co-regulation을 학습한다.

## 2. 왜 중요한가

4,200개가 넘는 sample과 30여 tissue에서 pretraining해 ligand–receptor interaction, spatial co-localization, disease-specific gene-neighborhood rewiring과 population-level perturbation effect를 분석한다. 독립 cell encoder 중심 scFM의 tissue-context 한계를 직접 겨냥한다.

## 3. 내 연구에 연결할 점

Rejection의 immune–endothelial–tubular 상호작용을 biopsy 단위로 모델링하는 데 잘 맞는다. Cell set 구성과 cell proportion이 예측을 지배할 수 있으므로 donor-level split, composition-matched baseline, measured spatial evidence가 필요하다.
