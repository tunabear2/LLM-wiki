# Explicit Mechanistic Operators in Predictive Virtual Cells: Evidence, Failure Modes, and a Minimum Falsification Framework for Single-Cell Perturbation Prediction

## 1. 한 줄 요약

Predictive virtual cell에서 explicit biological mechanism의 추가 가치를 주장하려면 capacity-matched static·learned-dynamics model, late fusion과 topology-rewired control을 잠근 조건에서 비교해야 한다고 제안한다.

## 2. 왜 중요한가

최근 single-cell perturbation benchmark의 순위가 split, statistical unit, effect size, gene set과 metric에 따라 달라지고 여러 deep·foundation model이 단순 no-change·mean-effect·linear baseline을 넘지 못하는 사례를 정리한다. Mechanistic operator 자체의 incremental value를 분리하는 최소 falsification framework를 제시하지만, 새로운 구현이나 성능 결과는 없는 prospective design이다.

## 3. 내 연구에 연결할 점

Kidney rejection perturbation model에 GRN, pathway 또는 ligand–receptor prior를 넣을 때 같은 parameter budget의 static·learned-dynamics control과 rewired prior를 함께 비교해야 한다. Donor·cell type·drug OOD split과 사전 고정 endpoint로 기전 prior의 실제 추가 가치를 검증할 수 있다.
