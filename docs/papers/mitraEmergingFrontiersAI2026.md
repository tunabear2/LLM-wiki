# Emerging Frontiers for AI in Single-Cell Genomics

- Source/date: PubMed / Molecular Cell, published and indexed 2026-10-15

## 1. 한 줄 요약

scRNA-seq·scATAC-seq foundation model, multiome regulatory modeling과 Perturb-seq virtual cell을 연결해 single-cell AI의 현재 한계와 다음 연구 방향을 정리한다.

## 2. 왜 중요한가

초기 embedding과 foundation model이 실험 연구자에게 널리 쓰이지 못한 이유를 짚고, 대규모 atlas, epigenetic multiomics와 perturbation data가 주는 새 기회를 설명한다. Representation 성능과 규제·인과적 해석을 구분하는 최신 관점을 제공한다.

## 3. 내 연구에 연결할 점

Kidney transplant atlas를 scRNA annotation에만 쓰지 않고 chromatin, multiome 및 Perturb-seq 근거와 연결할 roadmap이다. 모델 규모보다 임상 질문, donor/center 외부 검증과 기능 실험의 연결을 우선해야 한다.
