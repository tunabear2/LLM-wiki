# LLM Bio Wiki

이 Wiki는 LLM, Transformer, single-cell foundation model, bioinformatics AI를 정리하기 위한 개인 지식 저장소입니다.

## 주요 주제

- LLM 기본 개념
- Transformer architecture
- Attention mechanism
- Tokenizer
- Fine-tuning
- RAG
- scGPT
- Geneformer
- Transcriptomics preprocessing
- Single-cell foundation models
- 장기 이식 예후 예측 모델 설계
- Microarray-to-scRNA prognosis adapter
- Article / report scrap notes

1. 핵심 개념
2. 왜 중요한가?
3. 수식 또는 구조
4. 예시 코드
