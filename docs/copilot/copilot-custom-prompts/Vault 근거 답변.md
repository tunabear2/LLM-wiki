다음 질문 또는 선택문에 대해 Vault 검색 결과에 근거한 답변을 작성하라.

{}

요구사항:
- 결론을 먼저 제시한다.
- 모든 핵심 주장과 수치를 실제 출처 노트에 연결한다.
- 검색 근거가 없는 내용은 만들지 말고 `현재 Vault에서 근거를 찾지 못했습니다`라고 쓴다.
- 확인된 사실, 해석, 제안을 구분한다.
- 상충하는 기록은 최신 active report를 우선하되 충돌을 밝힌다.
