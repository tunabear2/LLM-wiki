# Article / Report Scraps

논문으로 정식 정리하기 전의 article, conference abstract, report, blog, white paper 스크랩 노트를 모아두는 공간이다.

원문 전체를 복사하기보다 출처, 핵심 요약, 중요한 수치, 내 연구에 연결되는 아이디어를 중심으로 정리한다.

## Transcriptomics / Foundation Model

## 정리 기준

- 공개 URL 또는 DOI를 반드시 남긴다.
- PDF 원문은 repo에 직접 넣지 않고 Zotero, Obsidian attachment, 로컬 다운로드 폴더에 둔다.
- 핵심 문장은 짧게만 남기고, 나머지는 내 말로 요약한다.
- 내 연구와 연결되는 실험 아이디어, 주의점, follow-up question을 별도로 적는다.
